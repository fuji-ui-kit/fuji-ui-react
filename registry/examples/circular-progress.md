## Determinate

The arc eases to every new value.

```tsx
<CircularProgress value={68} label="Upload progress" showValue />
```

## Indeterminate

Omit value for work of unknown length.

```tsx
<CircularProgress label="Loading" />
```

## Sized

size takes a named step or a diameter in px.

```tsx
<CircularProgress value={40} size={120} thickness={8} label="Storage used" />
```
