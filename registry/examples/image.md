## With ratio

```tsx
<Image src="/photo.jpg" alt="" ratio={16 / 9} />
```

## Fullscreen preview

Click the image to open it fullscreen. Escape or clicking outside closes it.

```tsx
<Image src="/photo.jpg" alt="Forest path" ratio={16 / 9} fullscreen />
```

## Error fallback

```tsx
<Image src="/broken.jpg" alt="" ratio={1} />
```
