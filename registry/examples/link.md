## Underline styles

always (default), hover-only, and none.

```tsx
<Link href="/docs">Always</Link>
<Link href="/docs" underline="hover">Hover</Link>
<Link href="/docs" underline="none">None</Link>
```

## Blue link

A restrained, accessible link blue, not a dark saturated blue.

```tsx
<Link href="/docs" tone="blue">
  Learn more
</Link>
```

## Inline and external

```tsx
<Link href="https://example.com" target="_blank" rel="noreferrer">
  changelog
</Link>
```
